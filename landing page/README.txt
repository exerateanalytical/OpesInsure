OPESINSURE DESKTOP SCREENS + ARTEFACTS PACKAGE

This package contains the curated desktop website screens, category directories, marketplace / compare-buy flow screens, desktop artefacts, and written generation specifications for OpesInsure.

Important:
- Rejected screens are intentionally excluded.
- Collaged/asset-sheet mistakes are excluded.
- The life detail screens were not packaged because the final variants were not approved.
- Functional UI controls and icons should remain native components in implementation; use Lucide for UI/action icons.
- Insurer/provider logos should be replaced in production with official source assets.

Folder guide:
- screens/public_pages: public marketing pages such as Home, About, Contact.
- screens/auth: website login and sign-up pages.
- screens/marketplace_hub: the main insurance marketplace / buy insurance hub.
- screens/category_directories: public insurance category directory pages.
- screens/compare_buy_flow: the desktop quote/compare/buy flow stages in generation order.
- artifacts/desktop_generated_assets: standalone artefacts generated from desktop screen language.
- artifacts/desktop_extracted_assets: individually extracted assets from the approved marketplace screen.
- specifications: generation specifications, manifest, and packaging notes.
