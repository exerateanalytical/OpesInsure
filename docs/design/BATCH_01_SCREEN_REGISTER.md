# Batch 01 Administrative Screen Register

Every screen uses the OpesInsure tokens, 12-column desktop grid, 4-column mobile grid, 44 px targets, Lucide outline icons and explicit loading/empty/error/permission states. No carrier branding controls platform navigation.

| Module | Screens | Primary Lucide icons |
|---|---|---|
| Tenancy | Organization list/detail/create/edit; branches; members; invitations; tenant settings; suspension confirmation | `Building2`, `Network`, `Users`, `MailPlus`, `Settings2`, `ShieldOff` |
| Identity | Sign in; MFA; recovery; profile; password; trusted devices; sessions; security activity; OAuth clients | `LogIn`, `ShieldCheck`, `KeyRound`, `UserRound`, `Smartphone`, `MonitorSmartphone` |
| Customers | Directory; create; profile; contacts; addresses; consents; duplicate review; activity | `UsersRound`, `UserPlus`, `Contact`, `MapPin`, `BadgeCheck`, `GitMerge` |
| Partners | Directory; onboarding; licence list/detail/submission/decision; compliance timeline | `Handshake`, `BadgePlus`, `FileBadge`, `Scale`, `History` |
| Attribution | Attribution detail; create; history; dispute intake; review; resolution | `Link2`, `LockKeyhole`, `History`, `MessageSquareWarning`, `Gavel` |

Forms are one-column up to 720 px and never place more than two related inputs in a desktop row. Destructive actions are separated from primary actions. Status always includes text and icon; color is supplementary. Tables retain horizontal scrolling instead of compressing or distorting columns.
