# OpesInsure Document Requirement Matrix by Insurance Type v1.0 — owner specification (2026-09-24)

Connects Product → Lifecycle stage → Document → Issuer → Recipient → Trigger. The 220-document register never operates as a loose library: every product version declares which documents apply.

Levels: **M** mandatory · **C** conditional · **O** optional · **I** internal · **T** third-party supplied. "C/M" = conditional or mandatory by insurer; "M/C" = mandatory unless the insurer's product says otherwise.
