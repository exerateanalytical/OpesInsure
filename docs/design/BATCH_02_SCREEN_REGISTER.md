# Batch 02 Screen Register

All screens inherit Batch 1 tokens and component behavior. Desktop uses a 12-column grid and mobile uses a 4-column grid with 16 px margins. Tables scroll horizontally at narrow widths and never compress data into unreadable columns. Carrier logos appear only inside neutral product/offer containers.

| Module | Screens | Lucide icons |
|---|---|---|
| Catalogue | Insurance lines; product directory/detail; product version editor; coverage builder; eligibility; publish review | `LibraryBig`, `PackageOpen`, `Layers3`, `ShieldPlus`, `ListChecks`, `Send` |
| Tariff & Rating | Tariff directory; version editor; factor builder; tax/levy rules; fee schedule; approval comparison; calculation trace | `Calculator`, `GitCompareArrows`, `Percent`, `Landmark`, `ReceiptText`, `BadgeCheck`, `Route` |
| Risk Assets | Asset directory; vehicle/property/traveller/member profile; document links; risk history | `Boxes`, `CarFront`, `House`, `Plane`, `HeartPulse`, `Files`, `History` |
| Quotes | Quote intake; risk review; rating progress; offer comparison; referral; decline; acceptance; expiry | `FilePlus2`, `ScanSearch`, `LoaderCircle`, `Columns3`, `CircleHelp`, `ShieldX`, `CircleCheckBig`, `Clock3` |
| Proposal & Underwriting | Proposal editor; disclosures; requirements; submission review; queue; case detail; decision; counteroffer | `ClipboardPenLine`, `MessageSquareText`, `ListTodo`, `Send`, `Inbox`, `ClipboardSearch`, `Gavel`, `RefreshCcwDot` |

Offer comparison uses aligned columns for premium, fees, taxes, coverage, deductible and exclusions. A recommended indicator is permitted only when its ranking criteria are disclosed. No dark-pattern preselection is allowed.
