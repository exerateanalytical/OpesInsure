# Batch 06 Insurance Control-Plane Screens

These screens are insurance-specific. Metrics use explicit definitions, effective dates and FCFA tabular numerals. Charts never replace exact tables where regulatory or financial accuracy matters. Carrier and broker branding is secondary to OpesInsure navigation.

| Module | Screens | Lucide icons |
|---|---|---|
| Insurance analytics | Portfolio overview; GWP; policies; claims; loss ratio; conversion; commissions; renewals; carrier comparison; exports | `ChartNoAxesCombined`, `BadgeDollarSign`, `ShieldCheck`, `ClipboardPlus`, `Percent`, `ChartFunnel`, `BadgePercent`, `RefreshCw`, `Columns3`, `FileDown` |
| Regulatory configuration | Reference sets; CIMA/MINFI codes; geography; tax/levy; calendars; version comparison; approval | `LibraryBig`, `Landmark`, `Map`, `ReceiptText`, `CalendarDays`, `GitCompareArrows`, `BadgeCheck` |
| Integration platform | API clients; scopes; keys; webhook subscriptions; delivery attempts; sandbox; usage; revocation | `Cable`, `ListChecks`, `KeyRound`, `Webhook`, `ListRestart`, `FlaskConical`, `Gauge`, `Ban` |
| Broker operations | Book of business; bordereaux; renewal workbench; expiry calendar; production; commissions; carrier submissions | `BriefcaseBusiness`, `Rows3`, `RefreshCw`, `CalendarClock`, `ChartColumnBig`, `BadgePercent`, `SendHorizontal` |
| Carrier operations | Portfolio intake; bordereaux review; delegated authority; authority check; issuance queue; claims exchange; acknowledgements | `Building2`, `ClipboardCheck`, `ShieldEllipsis`, `ScanSearch`, `Inbox`, `ArrowLeftRight`, `CheckCheck` |

Loss ratio is labelled as estimated when based on claim estimates rather than paid/incurred carrier data. Ranking tables disclose their sorting measure and date window.
