# Wave 11 security matrix

| Surface | Control |
|---|---|
| Release candidate | Immutable version/commit identity and optimistic lock |
| Gate evidence | Canonical evidence hashing, named assessor and timestamp |
| Certification | Maker-checker separation; all seven gates required |
| Findings | High/critical unresolved findings block certification |
| Recovery | Explicit RTO/RPO targets and measured exercises |
| API | JSON-only mutations, no-store responses, nosniff, restrictive permissions/referrer policy |
