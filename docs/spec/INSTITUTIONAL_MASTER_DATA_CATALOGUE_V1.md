# OpesInsure Institutional Master Data Catalogue v1.0 — owner specification (2026-09-24)

Full 126-section text supplied by the owner in session 2026-09-24. Locked essentials:

- **Rule:** select standardized values; free text only when no value exists. Reusable insurance concept → master data (make, occupation, property type, crop, cargo type); transaction-specific value → manual (VIN, income, address, farm size, shipment value).
- **Pattern:** Category → Subcategory → Standard value → Attributes → Aliases → Source → Status → Effective dates. Canonical codes stored (e.g. PROPERTY_WAREHOUSE), labels translated EN/FR with descriptions.
- **Fallback never blocks a transaction:** Other / Not Listed → proposed value → transaction completes → review request (statuses SUBMITTED, UNDER_REVIEW, DUPLICATE_FOUND, APPROVED, MERGED, REJECTED, ARCHIVED) showing proposer, tenant, screen, suggested category, possible duplicates, submission count; frequent ones prioritized; raw input kept for audit.
- **Provenance:** source_type (REGULATORY, GOVERNMENT, CIMA, INSURER, BROKER, MANUFACTURER, INDUSTRY, PLATFORM_NORMALIZED, MANUAL_VERIFIED, USER_SUBMITTED), source_reference, verified_at/by, effective_from/until. Never delete referenced values — INACTIVE instead.
