# Batch 05 Security and Trust Matrix

| Control | Enforced now | Remaining production gate |
|---|---|---|
| Delivery custody | Guarded transitions, courier/actor events, coordinates and evidence | Courier mobile attestation and device integrity |
| Proof of delivery | Hashed OTP required for delivered state | SMS delivery and retry provider |
| Notification privacy | Destination stored as hash; purpose/channel preference check | Encrypted dispatch destination vault and provider adapters |
| Mandatory notices | Security and transactional notices cannot be disabled | Legal review of mandatory communication catalogue |
| Complaints | Separate type, SLA clock, guarded escalation/resolution | MINFI/CIMA escalation contacts and reporting format |
| Fraud safeguards | Rules versioned/hashed; scores create alerts, not automatic adverse decisions | Rule executor, sanctions/PEP providers and model governance |
| Human decision | Named decision, notes and audit required | Dual approval for account freeze or payout block |
| Privileged access | Separate approver, purpose, justification, start and expiry | Runtime middleware enforcing active grants and session recording |
| Audit | Permission-controlled explorer and chained entries | Concurrency-safe hash anchoring and immutable external archive |
| Data rights | Tracked access/correction/deletion/restriction/portability/objection requests | Jurisdiction-specific legal deadlines and fulfilment automation |
